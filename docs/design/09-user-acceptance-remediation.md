## 安全前置条件

用户在本地 `.env` 中使用过真实 DeepSeek Key，并在对话中暴露了可识别前缀。该 Key 必须视为已泄露：

1. 在供应商后台作废旧 Key。
2. 生成新 Key 后仅写入被忽略的本地 `.env`。
3. 在轮换完成前不再执行 live 调用。
4. 仓库和文档不记录旧 Key、新 Key、前缀、Base URL 值或模型值。

Key 作废需要用户在供应商后台操作，项目代码无法代为完成。
