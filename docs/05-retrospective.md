# 05 项目复盘

## 最难的问题

### 证明动态决策

仅有条件分支或预写日志不能满足 ReAct。解决方式是让适配器只返回结构化动作，工具产生观察，再把观察传回相同决策接口。Trace 的后续动作从实际相邻事件生成。

### 防止旧报告复用

每个脚本包含 revision 和 fingerprint，检查报告同时绑定二者。脚本内容改变后旧报告失效，且任何再次提交都必须严格增加 revision，避免用相同指纹和旧版本号绕过检查。

### 离线复现与真实入口

Mock 与真实模型共用动作、图、工具和守卫，并明确 Mock 边界。真实效果仍需有密钥时实测。

### 事实追溯

分镜同时保存 `source_ids` 和 `fact_ids`，规则工具验证事实归属，并检查素材未提供的数字或比例。

## 学习收获

- LangGraph 的价值是把状态、循环、守卫和终止变成可测试接口。
- 空结果、业务拒绝、异常和超时必须区分。
- 完成守卫应验证结果，但不能替模型选择修订动作。
- Trace 记录公开依据和观察即可，不需要内部思维过程。
- Mock 适合验证确定性工程行为，不能替代真实模型评估。
- Trace 必须区分模型提议与实际执行；记录被工具忽略的字段会形成虚假证据。
- 历史运行缺少元数据时应明确标记不可追溯，不能用当前配置回填。
